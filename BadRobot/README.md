# BadRobot reference code

This folder contains reference code and the `Physical_World_Malicious_Queries.xlsx` dataset from:

> Zhang et al. (2024). *BadRobot: Jailbreaking Embodied LLMs in the Physical World.* [arXiv:2407.20242](https://arxiv.org/abs/2407.20242)

It is **not my work**. It's included for research comparison only. My own implementation of the BadRobot techniques, adapted for multi-turn attacks on the Blue Agent, is in [`agents/badrobot_red_agent.py`](../agents/badrobot_red_agent.py).

Please refer to the original authors' repository for licence terms.
